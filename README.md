# 💬 Quick Chat

A modern real-time chat application built using **Node.js**, **Express.js**, **MongoDB**, and **Socket.IO**. Quick Chat enables users to communicate instantly through a simple, responsive, and secure interface.

---

## 🚀 Features

- 🔐 User Authentication (Sign Up & Login)
- 💬 Real-Time Messaging with Socket.IO
- 👤 User Profile Management
- 🟢 Online User Status
- 📱 Responsive User Interface
- 🗂️ Persistent Chat History using MongoDB
- ⚡ Fast and Lightweight Performance
- 🔒 Secure Session Management
